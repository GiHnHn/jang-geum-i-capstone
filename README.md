# 장금이 · 캐릭터 기반 AI 요리 어시스턴트

**백종원 유튜브 레시피를 찾아 캐릭터의 말투와 합성 음성으로 요리를 안내하는 웹 서비스입니다.** 조리 중 재료 대체나 맛 조절을 질문하고 음성으로 답변을 받을 수 있습니다.

2025.03–06 · 졸업설계 · 3인 팀 / 팀장 한기헌

React · Express · GPT-4o · n8n · GPT-SoVITS

<img src="docs/images/recipe-chat.png" alt="장금이 레시피 대화 화면" width="640" />

## 담당 작업

- 백종원 레시피·음성 데이터를 수집하고 **GPT-SoVITS 음성 모델을 학습**했습니다.
- n8n에 유튜브 자막·쇼핑 검색을 연결하고, 자막 라이브러리를 활용한 커스텀 노드를 제작했습니다.
- Colab 모델을 호출하는 FastAPI 서버를 구성해 시연에 연결했습니다.

서비스 전체는 팀 결과물이며, 위 항목은 개인 담당 작업입니다.

## 핵심 구현

유튜브 자막을 답변의 근거로 활용하고, 프롬프트로 캐릭터 말투를 구성했습니다. 응답 품질과 속도를 비교해 대화에는 GPT API를, 캐릭터 목소리에는 학습한 GPT-SoVITS를 적용했습니다.
