# 공개용 정리 내역

2026.09.22, 보관한 `web_App` 소스와 자막 노드를 공개용으로 정리했습니다. 백업·생성 파일·인증정보 등을 제외하고 실행 환경 설정을 정비했습니다. 이 과정에서 초기 화면과 최종 흐름이 함께 있는 파일도 남겼습니다.

## 설치·빌드 환경 정비

- 외부 주소·인증 설정을 환경변수로 분리하고 인증정보 디버그 출력 제거
- 누락된 의존성·모델 import, 라우터 등록과 환경변수 초기화 순서 수정
- 미사용 상태·중복 분기·타이머 취소 로직 정리
- 의존성 잠금 파일과 환경변수 예시 정비

위 작업은 공개용 설치·빌드 환경을 정리한 내용입니다. 졸업설계 당시 맡은 개발 내용은 [README의 담당 역할](../README.md#맡은-역할)에 따로 적었습니다.
