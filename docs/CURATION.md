# 공개본 정리 기록

정리 기준: 2026-09-22. 원본 폴더를 삭제하거나 덮어쓰지 않고 별도 복사본을 구성했습니다.

## 장금이

기준 소스는 로컬 `web_App`입니다. GitHub의 과거 `final-jang`보다 로컬에 변경 내용이 남아 있어 현재 로컬 파일의 정적 연결을 확인했습니다.

| 유지 | 근거 |
|---|---|
| React 진입점에서 연결되는 19개 파일 | import를 따라 화면·컴포넌트·스타일 연결 확인 |
| Express 서버, 실제 import된 routes/models | 서버의 직접 연결 확인 |
| `/api/test-command` | ChatUI에서 실제 호출하므로 이름만 보고 실험 코드로 삭제하지 않음 |
| 자막 커스텀 노드 1개 | 최종 보고서에서 설명한 외부 도구 연동의 소스 근거 |

| 제외 | 이유 |
|---|---|
| 가상환경, node_modules, dist/build, Firebase 캐시 | 로컬 환경·자동 생성물 |
| .env, 서비스 계정 JSON, Git 설정, 인증키 | 실행 환경별 인증 자료 |
| checkpoint/test/백업 파일, 미연결 routes/models | 현재 실행 시작점에서 연결이 확인되지 않음 |
| 기본 React 테스트·로고·미사용 CSS·CharacterProfile | 진입점에서 참조되지 않거나 기본 템플릿 |
| 모바일·RAG·자체 LLM 학습 실험 | 최종 웹 경로와 별개이거나 채택하지 않은 접근 |
| 녹음·모델 가중치·대용량 영상 | 간결한 코드 검토와 재현 범위에 불필요 |
| n8n HttpBin 예제·빈 credentials 템플릿 | 자막 노드와 무관 |

### 2026년 복사본에서 보완한 부분

- 화면에 고정된 예전 백엔드 URL을 환경변수와 localhost 기본값으로 변경.
- n8n 및 외부 TTS 주소를 환경변수로 분리.
- 선언되지 않은 프론트엔드 axios 의존성을 명시하고 잘못된 React `setUser` import 제거.
- Express Router를 함수처럼 호출하던 부분을 올바르게 연결.
- `User` 모델 import 및 환경변수 초기화 순서 보완.
- 사용하지 않는 서버 import를 제외하고 요청 헤더·쿠키의 디버그 출력 제거.
- Google 인증 파일 경로를 운영체제 임시 폴더 기준으로 바꾸고 표준 인증 경로 지원.
- 기본 테스트용 ESLint 설정을 제외하고, 중복 case·상수 비교·미사용 상태값·타이머 취소의 잘못된 함수 호출을 정리.
- 잠금 파일과 환경변수 예시를 정리본 기준으로 새로 생성.

이 보완은 공개 정리를 위한 유지보수입니다. 당시 개발 성과를 추가한 것으로 쓰지 않습니다. 기존 회원/로그인/기록 흐름에는 미완성 연결이 남아 있어 README에 제한을 표시했습니다.


독립 저장소로 옮기면서 README를 캐릭터·레시피·음성 경험과 확인된 개인 담당 작업 중심으로 수정했습니다.

### 공개 전 확인

- 서버·프론트엔드 각각 `npm ci` 성공. 프론트엔드 잠금 파일의 TypeScript peer 의존성 불일치를 정리했습니다.
- 서버 `node --check server.js` 통과.
- 프론트엔드 `CI=true npm run build` 성공.
- 외부 API·n8n·음성 서버를 연결한 전체 서비스 실행은 확인하지 않았습니다.
