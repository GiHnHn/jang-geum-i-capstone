# 개발 과정과 개인 기여

2025년 개인 격주보고서, 팀 최종보고서와 발표자료를 대조한 기록입니다.

| 시기 | 개인 보고서에서 확인한 작업 |
|---|---|
| 03.16~03.22 | Raspberry Pi 환경 구성과 모델 실행 가능성 검토, 조미료 장치 구상 |
| 03.30~04.05 | 백종원 레시피 수집, QA 데이터 제작, 한국어 LLaMA3 학습 시도 |
| 04.16~04.29 | GPT-SoVITS 음성 학습, 추가 데이터 수집과 품질 개선 시도 |
| 05.07~05.14 | Colab 모델을 FastAPI로 호출, 중간 시연영상 제작, 지연 확인 |
| 05.15~05.28 | n8n 에이전트·쇼핑 검색·한국어 자막 추출 흐름 구성 |

레시피 데이터는 초기에는 파인튜닝용 QA 제작에 사용했고, 후반에는 요청과 가까운 유튜브 영상의 자막을 실시간으로 가져와 답변 근거에 사용하는 흐름으로 발전했습니다.

백종원 캐릭터의 말투는 프롬프트, 목소리는 학습한 음성 합성 모델로 구성했습니다. 최종 시스템에서 자체 언어모델 학습을 채택하지 않았다는 설명이 음성 학습도 하지 않았다는 뜻은 아닙니다.

보관 노드의 기본 언어값은 `en`이며, 보고서의 한국어 수집은 워크플로우에서 `ko`를 지정하는 구성으로 해석했습니다. 보고서의 MCP 표현과 별개로, 공개 파일은 n8n 노드 소스입니다. 별도 MCP 서버 구현으로 소개하지 않습니다.

2024년 2학기 공학설계의 선행 구상과 2025.03~06 공식 졸업설계 기간을 구분했습니다.
